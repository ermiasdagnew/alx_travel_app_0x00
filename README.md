# 🌍 alx_travel_app_0x00

## 📘 Project Overview
This project demonstrates database modeling, serialization, and data seeding in Django.  
It defines models for listings (properties), bookings (customer reservations), and reviews (customer feedback).  
It also includes serializers for API representation and a management command to seed the database.

---

## 🧩 Features
- Django models with relational fields (`ForeignKey`, `OneToMany`)
- Django REST Framework serializers for `Listing` and `Booking`
- Database seeding using `django-seed` and custom management commands
- Unit tests for models, serializers, and seeders
