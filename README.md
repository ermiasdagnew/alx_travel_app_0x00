# alx_travel_app_0x00

## Project Overview
This project demonstrates database modeling, serialization, and seeding in Django. It includes:

- Listings (properties)
- Bookings (customer reservations)
- Reviews (customer feedback)

## Features
- Django models with proper relationships (ForeignKey)
- Django REST Framework serializers
- Database seeding using `django-seed`
- Unit tests for models, serializers, and seeders
